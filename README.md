### Overview
**Kerna HR System** redefines human resource management by integrating intelligent employee tracking, automated payroll systems, and AI-assisted recruitment pipelines within a seamless JavaScript architecture.

### Core Architecture
- **Interactive UI:** A fluid `React` frontend designed for HR professionals to manage vast employee data effortlessly.
- **Scalable Data:** Leverages `MongoDB` for flexible, document-based storage of employee records and analytics.
- **Containerization:** Deployed using `Docker` to ensure consistent performance across all enterprise servers.
